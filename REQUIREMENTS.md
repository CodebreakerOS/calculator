# Requirements

Before the calculator is complete it must have all of these functions:

1. Addition
	The calculator must be able to add any two given numbers together
2. Subtraction
	It also must be able to subtract any two given numbers away from each other
3. Multiplication
	And multiply any two given numbers together
4. Division
	And divide any two given numbers
5. Displaying a result
	Once the operation (s) have been computed, the calculator must give the result back to the user through a CLI.

## Expected results

Input: 6 + 13
Result: 19

Input: 35 / 0
Result: Error
